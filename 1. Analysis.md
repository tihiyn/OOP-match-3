1. В систему будет включено:
   - заполнение сетки случайными элементами
   - интерактивный ввод для перестановки элементов
   - бонусы
   - учёт статистики
   - комбинации
   - игровое поле (сетка)

    В систему не следует включать:
   - уровни
   - интернет

2. Главные подсистемы:
   - подсистема учёта статистики
   - подсистема бонусов
   - подсистема распознавания комбинаций
   - подсистема взаимодействия с консолью
   - подсистема сетки

3. Пользовательские метафоры:
   - сетка - матрица размером 8х8
   - игрок - пользователь, который взаимодействует с системой
   - бонус - за более сложные комбинации игроку доступно одно случайное действие: удаление всех элементов одного типа, 
   удаление ряда, удаление столбца
   - статистика - кол-во очков и кол-во ходов игрока
   - элементы сетки - символы A, B, C, D, E
   - комбинация - определённые сочетания элементов сетки

4. Функциональность:
   - начать игру
   - переставить соседние элементы
   - увидеть статистику
   - использовать бонусы
   - перезапустить игру
   - завершить игру

5. Библиотеки повторного использования:
   - стандартная библиотека языка
   - библиотека генерации случайный чисел
   - библиотека для работы с консолью
